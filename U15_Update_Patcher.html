🏀 U15 Basketball Scout 更新パッチャー

既存アプリの index.html を選択すると、既存コードを残したまま録画・ローカル保存・オフライン用キャッシュ機能・シュートリリース候補抽出・試合映像の動き分析パネルを追加し、更新版 index.html を作成します。

使い方
  1. GitHubのU15-Basketball-Scout2026から現在の index.html を端末にダウンロードします。
  2. このページでそのファイルを選択します。
  3. 「更新版を作成」を押し、出力された index.html を保存します。
  4. GitHub Pagesのリポジトリ内の index.html を、この更新版に置き換えます。
